# Implementation TODOs

```sh
rg -n 'TODO\(I-[0-9]+\):|BLOCKED\(I-[0-9]+\):|LEAKY ABSTRACTION:' src scripts tests
```

Marker meanings:

- `TODO(I-###):` is remaining bounded work owned by that package.
- `BLOCKED(I-###):` names a measured external or decision blocker and its required evidence.
